# Delivery memory cases

One markdown file per finished run, written by `MemoryHub.harvest()` alongside
an `index.json` used for retrieval. Each case records the objective, the
problem, the solution and — the part that earns its keep — the **pitfalls**.

Before an `ArchitectStage` drafts a plan, the hub retrieves the closest cases
and injects their pitfalls as plan constraints, weighting past *failures* above
past successes. Cases are committed deliberately: they are review artifacts, so
edit or delete one that records a lesson wrongly.

See `docs/spec-driven-delivery.md` §4.
